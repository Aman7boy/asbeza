# Asbeza

A marketplace platform connecting traders, customers, and boards.

## Features

- **Trader Dashboard**: Manage products, orders, and inventory
- **Board Management**: Oversee marketplace operations
- **Customer Experience**: Browse and purchase products
- **Near Me**: Location-based product discovery
- **Multi-language Support**: English and Amharic

## Tech Stack

- React + TypeScript
- Cloudflare Workers
- D1 Database
- Vite

## Development

```bash
bun install
bun run dev
```

## Deployment

Deployed via Freebuff Sites to Cloudflare Workers.
